# ODOCH — Software • Data • AI • Business • Africa

Personal technology brand and portfolio of Brian Odoch Emmanuel.

## Website direction
- Timeless, restrained visual identity using deep navy, green, and white.
- Responsive, accessible, fast-loading static website.
- Clear introduction, professional profile, focus areas, selected projects, and contact links.
- Use the approved ODOCH logo; do not recreate or distort the wordmark.
- Avoid unsupported superlatives or claims. Keep the biography factual and editable.

## Deployment
This repository is intended for GitHub Pages. The site should work as a static site without paid services or a backend dependency.
